# 위대한 청소부

특수청소, 쓰레기집 청소, 유품정리, 악취 제거 및 원상복구 서비스를 소개하는 반응형 랜딩 페이지입니다.

## 실행

```bash
npm install
npm run dev
```

## 운영 전 설정

대표 전화번호 또는 카카오톡 상담 채널이 확정되면 `src/main.jsx`의 상담 모달 제출 동작을 실제 문의 채널로 연결하세요. 현재는 개인정보를 서버에 전송하지 않고 상담 요청 문구를 클립보드에 복사합니다.

## 이미지

`public/images/`의 현장 이미지는 이 프로젝트를 위해 생성한 이미지입니다. `brand-original.png`는 제공받은 원본 로고 이미지입니다.
